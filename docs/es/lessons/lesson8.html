Lección 8: Interfaces (UI) y Señales Personalizadas

En esta lección aprenderemos a crear una interfaz de usuario (HUD) que nos muestre la vida de Aina en todo momento, y cómo utilizar señales propias para comunicar cambios en el juego de manera elegante.

1. Mundo vs. Interfaz: Control Nodes

En Godot hay una distinción fundamental entre los nodos que forman el mundo del juego y los que forman la interfaz:

  • El Mundo del Juego (2D Scene): Se mueven en el espacio del juego (metros, coordenadas del mundo).
  • El Mundo de la Pantalla (Canvas): Se mueven en el espacio de la pantalla (píxeles, anclajes). Son los botones, barras de vida y menús.

La UI siempre tiene que permanecer fija, independientemente de dónde esté la cámara. Para conseguirlo, necesitamos un nodo especial.

2. El CanvasLayer: El Ancla de la UI

Para crear la UI de la vida de Aina, crearemos una nueva escena con raíz CanvasLayer. El nodo CanvasLayer crea una capa de dibujo separada. Todo lo que coloquemos dentro de un CanvasLayer no se moverá cuando la cámara avance. Es como si la interfaz estuviera "pegada" al cristal de la pantalla.

📂 Jerarquía de la escena Vida.tscn

La nueva escena donde tendremos la barra de vida con imágenes tiene que seguir este esquema:

  1. CanvasLayer (Raíz)
  2. Control: Contenedor principal para posicionar la barra (por ejemplo, en la esquina superior izquierda).
  3. TextureProgressBar: El elemento visual que muestra la vida.
    • Texture Under: Aquí pondremos life.png (el marco vacío con el corazón).
    • Texture Progress: Aquí pondremos lifefull.png (los píxeles verdes).

3. La Barra de Vida: TextureProgressBar

Para visualizar la vida de Aina, usaremos un nodo TextureProgressBar. Este permite utilizar imágenes para el fondo (Under), la barra que se llena (Progress) y opcionalmente un marco (Over).

Propiedades clave:

  • Min Value / Max Value: Normalmente 0 y 100.
  • Value: El valor actual que determina cuánto se llena la barra.
  • Textures: Asigna los sprites de tu barra de vida en las secciones correspondientes del Inspector.

Coloca tu barra en la parte superior izquierda de la pantalla utilizando los Anchors (Anclajes) para asegurar que se mantenga allí en cualquier resolución.

4. Señales Personalizadas (Custom Signals)

Hasta ahora hemos usado señales integradas (como area_entered). Pero, ¿qué pasa si queremos avisar a toda la interfaz que la vida de Aina ha cambiado?

Podemos definir nuestras propias señales con la palabra clave signal.

Actualizando Globals.gd:

Vamos a hacer que nuestro script global avise cada vez que Aina recibe daño:

# Globals.gd
extends Node

# Definimos la señal personalizada
signal health_changed(new_health)

var aina_life = 100

func hurt(amount):
    aina_life -= amount
    # Emitimos la señal con el nuevo valor de vida
    health_changed.emit(aina_life)
    
    if aina_life <= 0:
        game_over()

5. Conectando la UI con el Código

El último paso es hacer que la barra de vida "escuche" la señal que hemos creado en el script Global.

En el script de la UI (por ejemplo, hud.gd):

extends CanvasLayer

@onready var health_bar = $TextureProgressBar

func _ready():
    # Conectamos la señal del Global a una función local
    Globals.health_changed.connect(_on_health_changed)
    # Inicializamos la barra con la vida actual
    health_bar.value = Globals.aina_life

func _on_health_changed(new_health):
    # Actualizamos visualmente la barra
    health_bar.value = new_health

De esta manera, cada vez que cualquier enemigo llame a Globals.hurt(), la UI se actualizará automáticamente gracias a la señal.

6. 🔗 ¿Cómo se incluye en el juego?

En lugar de meter la UI dentro de Aina, la meteremos dentro de nuestra Escena Principal (el nivel).

  1. Abre tu escena de nivel.
  2. Instancia (icono de la cadena) la escena Vida.tscn.
  3. Magia: Gracias al nodo CanvasLayer, aunque Aina corra kilómetros hacia la derecha y la cámara la siga, la barra de vida se quedará quieta en la esquina de la pantalla.

⚠️ ALERTA DOCENTE: Nunca metas los nodos de vida (como barras o corazones) como hijos de Aina o de la Cámara. Si lo haces, la barra "saldrá" de la pantalla cuando el personaje se mueva. El CanvasLayer crea una capa independiente que siempre está "pegada" al cristal del monitor del jugador.

🛠️ Tarea Práctica 8: Tu Primer HUD

Objetivo: Crear una barra de vida funcional que se actualice al recibir daño.

  1. UI: Crea un `CanvasLayer` y añádele una `TextureProgressBar` o `ProgressBar` a la parte superior izquierda.
  2. Señal: Define la señal `health_changed` en tu script `Globals.gd`.
  3. Emisión: Llama a `emit()` dentro de la función `hurt()`.
  4. Conexión: Conecta la señal en el script de la HUD para que la barra se mueva al perder vida.

Entrega: Tu proyecto comprimido en Aules.
