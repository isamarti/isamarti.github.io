🎒 Lliçó 9: L'Arquitectura de la Motxilla

Benvinguts a una de les lliçons més importants del curs. Fins ara, l'Aina podia rebre mal, però no podia guardar res. Avui aprendrem a crear la seua motxilla.

⚠️ Important: En aquesta lliçó ens centrarem exclusivament en el disseny visual i en la creació de dades. Deixarem la motxilla "llesta i bonica", però la "màgia" per a recollir objectes i usar-los la programarem en la Lliçó 10. Dividir la faena ens permetrà entendre millor com Godot separa la imatge de la informació.

1. El node GridContainer: L'aparador dels Objectes

Per a visualitzar la nostra motxilla, necessitem un contenidor que organitze els objectes de manera automàtica. Godot ens ofereix per a això el node GridContainer.

Aquest node agafa tots els seus fills i els ordena en una graella perfecta (de files i columnes) sense que hàgem de posicionar-los manualment a l'eix X o Y.

🛠️ Creant la UI de l'Inventari

  1. Afig un nou node GridContainer dins del teu CanvasLayer (pots crear una escena nova anomenada InventariUI.tscn o posar-ho dins de Vida.tscn per tindre tota la UI junta).
  2. En l'Inspector del GridContainer, canvia la propietat Columns al número de columnes que vulgues que tinga la teua motxilla (per exemple, 4 o 5).
  3. Afig diversos nodes TextureRect o panells com a fills del GridContainer per a representar les caselles (els "slots"). Veuràs com s'ordenen sols!

De moment, posa diverses caselles en blanc o amb un fons fosc, i ajusta dalt l'espai i el disseny perquè quede professional i bonic. Utilitza nodes de tipus MarginContainer si cal per donar espaiats atractius.

2. Custom Resources: Què és un Objecte?

A Godot, els Resources són contenidors de dades que no fan res per si mateixos, però guarden informació de manera molt eficient. A diferència dels Nods, els Resources no apareixen a l'Arbre d'Escenes i només guarden variables (com p.ex. la imatge d'una espasa, el pes o el seu nom).

Fins ara hem usat Resources "de fàbrica", com Texture2D per a les imatges. Ara crearem el nostre propi tipus de recurs personalitzat (Custom Resource) per a definir què és un "Item" (Objecte) al nostre joc.

📜 Codi del recurs Item (Item.gd)

Crea un script nou, però que no estiga assignat a cap node (Fes clic dret a l'explorador de fitxers i selecciona "Crea Nou -> Script"). Anomena'l Item.gd.

extends Resource
class_name Item

@export var name: String = ""
@export var description: String = ""
@export var texture: Texture2D
@export var quantity: int = 1
@export var max_stack: int = 99

Gràcies a la declaració class_name Item i la paraula clau @export, ara podem anar a l'explorador d'arxius, fer clic dret i escollir "Nou Recurs". Si busques "Item", podràs crear objectes infinits (ex. "Poma", "Poció") directament des de l'editor, ficant el seu nom, icona, i quantitat!

3. El cervell de la Motxilla: L'Array

La UI ja es veu, i sabem com definir objectes. Però on es guarden? Per a gestionar l'inventari en memòria utilitzarem una col·lecció de dades anomenada Array.

Un Array és com una llista ordenada o filera de caixes. La llista començarà des de la caixa 0 fins a la quantitat de caselles creades.

📜 Codi de la lògica de l'Inventari (Inventory.gd)

Ens interessa que la motxilla no forme part necessàriament de la UI, sinó que siguen dades universals. Crearem un altre Script (Inventory.gd) que actue com al gestor principal de dades.

extends Resource
class_name Inventory

# Creem un Array que contindrà elements de la classe 'Item'
# L'iniciem buit, amb espai per a diverses caselles que posem a 'null' (buit)
@export var slots: Array[Item] = []

func _init():
    # Quan es crea l'inventari, posem un tamany predeterminat
    slots.resize(16)

Així creat, tenim "forats" a l'Array que de moment estan buits (null). Més avant els anirem substituint per Resources reals d'objectes.

4. Connectant Dades i UI (Un xicotet avenç)

Hem fet la UI. Hem fet els Resources. Ara la UI ha de "saber" dibuixar eixos Resources. Si l'espai de l'Array està null, la UI ha de dibuixar l'slot buit. Si té un objecte (p.ex. una Poma), ha de dibuixar la seua icona i quantitat.

Com ho farem per a la pròxima lliçó? Deixarem preparades les eines. Afegirem una funcionalitat on polsant una tecla (ex. TAB o I) el node arrel de la motxilla es façe visible o invisible utilitzant visible = !visible.

En aquesta lliçó ens enfoquem exclusivament a tindre una UI increïble i la creació de les nostres estructures de dades en `.tres`. Deixar això resolt es fonamental.

🛠️ Tasca Pràctica 9: Preparant la Motxilla

Objectiu: Cuidar al màxim la part gràfica de l'inventari i preparar les dades Custom Resource.

  1. UI de l'Inventari: Fes servir un node GridContainer per a construir la teua interfície de Slots. Juga amb marcs, fons, transparències i marges fins que crees un panell d'inventari preciós per al teu personatge.
  2. Navegació amb Botó: Configura una drecera de teclat a l'Input Map (ex. tecla I) i programa l'escena principal per a ocultar/mostrar (visible = false / visible = true) aquesta nova UI a voluntat.
  3. La base de dables: Crea un script de Recurs personalitzat (class_name Item) seguint el codi d'escriptura.
  4. Crea els Teus Primers Objectes: Fes clic dret a l'explorador i crea almenys dos recursos nous tipus Item (ex. un diamant, una poma, o una destral). Configura visualment en l'inspector les imatges, els noms i les descripcions d'aquests recursos `.tres`.

Entrega: Puja l'arxiu ZIP del projecte. Em fixaré especialment en que la motxilla (la part visual i l'aparició/desaparició amb el botó) funcione suaument i siga bonica.
